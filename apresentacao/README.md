# Prévia para apresentar ao dono

- **apresentacao.pdf**: apresentação visual com 3 páginas, mostrando computador, categorias e celular. Abra o arquivo aqui no GitHub para visualizar ou baixar e compartilhar.
- **previa.html**: versão interativa em um único arquivo, com estilos, imagens e JavaScript incorporados. Abra o arquivo no GitHub, clique em **Download raw file** (ícone de download), salve com a extensão `.html` e abra no Chrome, Edge ou Safari. Não é preciso baixar outros arquivos ou instalar nada.

O mapa do Google e os links externos precisam de internet. O PDF é uma apresentação estática; os efeitos de hover e o menu podem ser experimentados no HTML.

Para ter um link público do site, importe `farenncinathan/site-sebo-amazonia` na Vercel e publique com o preset **Other**, usando a raiz do repositório. A configuração já está em `vercel.json`.
